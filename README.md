# 🤡 Happiness Project — A Little Dose of Stupid

> *"Having a bad day? Let's make it worse. (With jokes.)"*

A fun, quirky, retro comic-book style joke generator packed with terrible puns, classic dad jokes, silly one-liners, and playful Gen Z roasts. Built with pure HTML5, CSS3 (Neobrutalism), and modern JavaScript.

---

## 🎨 Features

1. **Heading & Concept**: "Having a bad day? Let's make it worse. (With jokes.)"
2. **Massive Action Button**: Oversized **"MAKE ME LAUGH 😂"** button with bouncy animations, synthesized comic sound effects, and confetti explosions.
3. **Categories**:
   - 👴 **Dad Jokes** (Certified groaner classics)
   - 🥐 **Silly Puns** (Terrible wordplay & food humor)
   - 🔥 **Roast Me** (Playful, relatable internet & lifestyle roasts)
   - ⚡ **All Chaos** (Random mix across all categories)
4. **Save the Cringe ⭐**:
   - Save favorite jokes to your personal **Cringe Museum** (persisted in `localStorage`).
   - Counter badge shows saved items in real time.
5. **Rating System**:
   - 💨 *I exhaled* (+1 dopamine token)
   - 💀 *Okay, that was good* (RIP your sense of humor)
   - 😭 *I'm crying* (Emotional damage confirmed)
   - Live vote counter and personal reaction saved per joke.
6. **The Cringe Museum (Favourites Page)**:
   - Dedicated tab to revisit all saved jokes.
   - Live search through saved jokes.
   - Category filtering.
   - Individual joke deletion or "Clear All" with funny confirmation.
   - Copy to clipboard for easy sharing.
7. **Joke of the Day**:
   - Fresh daily joke deterministically tied to today's date.
   - "Save to Cringe Vault" button.
8. **Extra Quirky Touches**:
   - **Emergency Roast Button**: Quick escape for awkward silences.
   - **Cringe-O-Meter**: Tracks jokes endured and estimated braincells lost.
   - **Synthesized Audio Engine**: Pure Web Audio API sounds (boing, pop, rimshot, sad trombone, chime, skull bonk, slide whistle) — 100% offline, zero audio asset downloads needed. Includes mute/unmute toggle.
   - **Speech Synthesis (Read Aloud 📢)**: Reads setup and punchline with dramatic comedic pauses.
   - **Keyboard Shortcuts**:
     - `Space`: Generate a new joke
     - `S`: Save current joke to Cringe Vault
     - `1` / `2` / `3`: Rate the joke (Exhale / Good / Crying)

---

## 🚀 How to Run

No installations, build steps, or servers required!

Simply open `index.html` in any web browser:
- Double-click `index.html`, OR
- Right click `index.html` → Open With → Chrome / Edge / Firefox / Safari.

Alternatively, serve with any local server:
```bash
npx serve .
# or
python -m http.server 8000
```
